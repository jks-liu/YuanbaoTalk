# 自动网关冗余与实时队列缺少边界

每台设备自动成为网关时，同一帧可能被重复上传和下行注入。服务器去重发生在接收后，不能消除已经消耗的无线和上行带宽。所有设备广播中继且 TTL 很大，会使语音失去实时性。

处理：首版接受有界冗余，明确每节点每帧一次转发、流数/队列/窗口上限和超限行为。共同协议提供含头部的容量估算：4 源、每帧 5 次无线发送约 832 kbit/s 应用数据，不能认为默认 PHY 下必然可用。

服务器建议独立 WebSocket 控制和媒体连接；定义流注册、代理去重、媒体绑定、截止时间、慢连接隔离和断网不补播。TCP 仍有队头阻塞，队列时限无法撤回已入 TCP 的数据，故同时约束接收端新鲜度并允许关闭积压连接。

状态：草案已补齐；部署规模和网络性能未实测。若弱网延迟不合格，需要完整设计 UDP 会话/路径协议，不能仅把传输名替换成 UDP。
