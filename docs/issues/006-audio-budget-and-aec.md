# 全双工前端与混音容量必须共同预算

2026-10-03 用户要求 PTT 期间收听，混音路数改为按性能自动选择且支持手动设置，并增加双麦 basic beamforming、NS 与 AEC。旧版固定四路及无 AEC 时按 PTT 静音的建议不再符合要求。

处理：新增音频规格；容量以双麦前端、AEC、NS、波束形成、发送编码、接收解码和双链路共同负载为依据，保留过载降档与恢复滞回，不能只按 PSRAM 推断。解码容量与网关转发独立，能力变化不会裁剪下游所需源。

AEC 参考改为最终实际播放 PCM，并覆盖音量、提示音和欠载；必须验收双讲而非仅远端单讲。BSS/MISO 不直接等价于固定方向波束形成，库的算法配置是否冲突要按锁定版本验证。

状态：文档规则已完成，真实双麦几何布局、算法选型和完整负载测量仍未完成；当前未编码。
