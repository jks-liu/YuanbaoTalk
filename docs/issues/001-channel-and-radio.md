# 业务频道与无线信道混淆

原始描述“同一个频道就能对讲”遗漏了无线信道和覆盖条件。ESP32 同一无线接口连接 AP 时，ESP-NOW 必须与 AP 同信道；连接不同信道路由器的两台设备，即使业务频道一样，也不能直接无线互通。

处理：业务频道采用统一 16 字节标识，数字与 UUID 使用不重叠命名空间；无线信道作为独立部署条件。固件规格明确 AP 换信道、跨信道和重新配网限制。

状态：文档已修正。离线寻网和换信道交互仍待具体产品配网设计，不承诺通话中扫描多个信道。

依据：[乐鑫 FAQ](https://docs.espressif.com/projects/esp-faq/en/latest/application-solution/esp-now.html)。
