# 多人混音缺少流边界与播放规则

原始 spec 未定义多人同时发言、编码帧、序号、抖动缓冲和结束包丢失时的行为。用户现已确认 PTT 期间收听、多源并发、按性能自动/手动选择混音路数，并指定 ESP32-S3 / 16 MB PSRAM；固定 4 路要求已在 2026-10-03 更新。

处理：每次 PTT 使用独立流；每路独立解码和排序，接收端对 PCM 混音；服务器与中继保留原始编码，禁止混音后再注入网络。自描述 AUDIO 支持 START 丢失和中途加入；END 允许尾帧排空，丢失则超时。超过有效容量 N 时稳定选流，额外流仍可转发。

状态：协议已明确。Opus 20 ms/16 kbit/s 为候选配置，需实测双麦前端+1 编码+N 解码+网络；PSRAM 不能替代 CPU 验证。PTT 边说边听已确认，支持波束形成/NS/AEC，声学回声与网络重复分别处理，见音频规格。
