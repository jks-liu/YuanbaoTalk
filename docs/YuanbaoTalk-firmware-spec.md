# YuanbaoTalk 固件规格

状态：v0.2 评审草案，2026-10-03。共同规则以 [协议规格](YuanbaoTalk-protocol-spec.md) 为准，音频实现要求见 [音频处理规格](YuanbaoTalk-audio-spec.md)。

## 1. 已确认范围

- 使用 ESP-NOW 直连和透明中继，服务器连接不同地域的同频道设备。
- 支持多人同时说话和混音，不能采用频道独占话权。
- 每台设备均可能连接 Wi-Fi/服务器，连接就绪后自动成为网关。
- 第一版不要求加密；UUID 仅为不易猜测的标识，不能宣称保密。
- 硬件按 ESP32-S3、16 MB PSRAM 设计；PTT 期间仍播放他人语音，默认按性能自动选择混音路数，设置中可手动指定。
- 支持双麦克风基础波束形成、噪声抑制（NS）与声学回声消除（AEC）。
- 用户已授权实现；具体实现和验证状态见 [开发交接](implementation-progress.md)。

## 2. 角色与频道

终端负责采集、编码、接收、逐流解码和本地混音；中继只转发编码包；网关桥接 ESP-NOW 与服务器，禁止重编码、合成新语音源或把扬声器输出当作网络转发输入。三种角色可在同一设备上共存。

每台设备第一版加入一个业务频道，只中继该频道。数字频道和 UUID 频道采用共同协议统一标识。换频道时结束本机流、退出旧订阅、停止旧频道转发并清空播放队列。

业务频道与无线信道是两个概念。同一无线接口连接 AP 后，ESP-NOW 必须与该 AP 同信道。相同业务频道但连接不同信道 AP 的设备，只能经服务器或其他独立无线接口通信。不能在通话期间靠反复切信道保证实时中继。

## 3. 发言和混音

采用 PTT 发送，发言时接收与播放继续。混音容量 N 默认自动选择，也可在设置中选择已验证范围内的手动路数；4 路保留为性能测试档位，不作为固定上限。多路音频按流独立排序、缓冲和解码，再按本地播放时钟混音；本机源始终排除。过载时按共同协议稳定选择接收流，不能逐包随机抢占解码器。

候选编码为单声道 16 kHz、20 ms、16 kbit/s Opus。在 ESP32-S3、16 MB PSRAM 上必须实测双麦前端（含 AEC/波束形成/NS）、1 路编码、N 路解码、混音和网络任务同时运行。PSRAM 容量不等于 CPU 预算，DMA/实时缓冲需按所选 IDF 和外设能力安排。无法满足预算时先减少混音路数；需换编码则统一修改音频 profile，不能由单台设备静默换编码。

PTT 松开后发 END；START/END 丢失通过自描述 AUDIO 和超时处理。建议单次发送最长 60 秒，超时提示并要求重新触发；持续免按键通话若需要，应另改流续期策略。

PTT 期间不得以关闭扬声器作为常规方案。外放时启用适合通话和双方同时说话的 AEC，参考取自实际送往扬声器的最终 PCM，含混音、音量、限幅和提示音；双麦同步采样、参考对齐、基本波束形成和 NS 的处理约束见音频规格。AEC 失败时提示音频故障，不悄悄退回半双工。

## 4. 中继与自动网关

中继建议默认开启但允许关闭；以小规模网络为首版边界。逐包去重后每个节点最多转发一次，随机延迟 0–5 ms 分散碰撞；默认 TTL=3，最大 16。密集网络的容量不能通过提高 TTL 解决。

服务器 READY 后立即具备自动网关能力，不依赖手工指定网关或唯一网关选举。所有网关可上传同一无线流，服务器去重；所有合格网关可注入服务器下行，无线节点去重。第一版接受有界冗余换取拓扑变化时的可达性，不宣称已实现最优路由。

每包的本地播放、无线转发、服务器上传分别记状态。已播放不意味着已经从所有必要出口转发；来自服务器的包及其无线后继禁止再次上传。详见共同协议的逐入口规则。

## 5. 断网与资源

本地发言不等待服务器许可；服务器并发满或断网时，本地仍可对讲，界面提示远端未送达。恢复网络只转发仍在产生的新音频，不补传旧音频；服务器允许网关为仍活动的原始流重新注册。

无线回调只做有限搬运和事件提交；编解码、播放和网络写入在工作任务执行。中继队列年龄上限建议 60 ms，服务器上传应用队列上限 100 ms；拥塞丢旧音频，不能积压后突发补播。ESP-NOW 发送成功不代表远端应用收到或已经播放。

必须限制流表、去重窗口、编解码器实例、发送队列和服务器连接数量。建议每节点最多跟踪 32 条活动/近期流，解码容量按音频规格计算；无法分配时拒绝新流并统计过载，不挤掉活动流的去重状态导致重复风暴。

## 6. 验收与待定

按共同协议场景检查多源混音、多网关防环、丢包、乱序、断网恢复与资源上限。记录端到端延迟、每路丢帧、队列丢弃、编码/混音耗时、峰值内存和声反馈情况。

待确认：具体模组、双麦间距/朝向、同步音频接口和扬声器/功放，总设备数/并发源/网关/跳数目标。PTT 期间收听已确认；所有性能参数尚未经硬件验证。
