# 实时多路径语音协议设计经验

1. 先区分原始源与每跳发送者。流身份跨无线和公网保持，才可以正确去重和混音。
2. 去重不是一个布尔值。播放和两个转发出口独立决策，入队也要原子预占，避免“已播放所以不再转发”或并发重复入队。
3. TTL、消息去重和服务器经过标志分别约束无线传播长度、重复次数和跨网回灌，需要同时定义。
4. 多人对讲应逐源转发、终端混音。服务器混音会丢失源身份，容易把本地已经听过的声音再次带回。
5. 广播覆盖不能靠听见重复包就安全停止转发；隐藏节点可能依赖本节点。优化冗余必须说明拓扑假设。
6. 实时语音应丢迟到包而不是追求每帧可靠送达。START/END 也不能成为唯一恢复依据，AUDIO 应包含足够的流信息。
7. 带宽估算要包含协议头、每秒包数、中继次数、自动网关副本和无线开销；编码码率远小于真实链路占用。
8. 缓存年龄、采样时间、播放截止和时钟偏移是不同概念；没有可信统一时钟就不能声称精确端到端过期或安全防重放。
9. 明确用户确认项、设计建议和性能假设，交接文档保留当前结论，不遗留已被纠正的半双工或专用网关方案。
