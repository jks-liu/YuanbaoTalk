# Spec 完善任务与进度

更新时间：2026-10-03。当前文档 v0.2；用户已授权实现，当前开发交接统一见 [implementation-progress.md](implementation-progress.md)。

## 已确认要求

- ESP-NOW 直连/中继，服务器跨地域同频道转发；每台设备均可自动成为网关。
- ESP32-S3 / 16 MB PSRAM；PTT 发言期间继续收听。
- 混音路数默认按性能自动选择，也可在设置中手动指定；不再固定为最多四路。
- 支持双麦基础波束形成、NS、AEC；首版无需加密。

## 已完成

- 固件、服务器、共同协议和音频规格已同步最新要求。
- 定义原始消息身份、TTL、去重、服务器经过标志及独立出口状态；多网关转发和恢复规则保持。
- 定义 N 路混音选流、平滑增益、完整前端负载下容量评估、手动设置与保护性降档；服务器能力更新不裁剪网关转发源。
- 定义双麦同步、基础波束形成、NS、最终播放 PCM 的 AEC 参考、双讲与性能验收。
- 说明 TTL=3 是未经实测的初值，含源首次发送，支持 1–16；不是用户已确认的默认值或芯片限制。
- 更新问题/经验/关键修改记录，查证官方 AFE 能力及双通道 BSS/NS 配置约束。

## 下一步

- 用户确认硬件尚未选型，先使用可配置标准 I2S；后续确定双麦型号、间距/朝向和扬声器布局。ESP-IDF 已确定为 6.1，音频组件已锁定版本。
- 确定设备/并发源/网关/跳数规模和 AP 配网交互；服务器 8 源、TTL=3 仍为建议。
- 实机阶段进行完整负载、AEC 双讲、波束方向/噪声和无线容量验证；不能承诺全功能 S3 已达到四路或更多。
- “暂不 coding”阶段已结束；已实现固件和服务器，没有烧录或部署。
